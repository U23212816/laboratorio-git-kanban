
# Informe del Laboratorio Git y Kanban

Durante el laboratorio utilizamos herramientas de gestión de proyectos en GitHub para organizar el trabajo colaborativo.

1. Se crearon **Issues** para dividir las tareas del proyecto y asignarlas según prioridad y tipo.
2. Se implementó un **tablero Kanban** con columnas To Do, In Progress y Done para visualizar el avance de cada tarea.
3. Se creó un **Milestone** para agrupar los objetivos del proyecto.
4. Se desarrolló una **Wiki** para documentar el propósito, planificación y flujo de trabajo del proyecto.
5. Cada tarea se registró y cerró mediante commits vinculados a los Issues usando la sintaxis `Fixes #N`.

Estas herramientas facilitaron la **organización, seguimiento y control de las tareas** del equipo, asegurando un flujo de trabajo eficiente y colaborativo.
